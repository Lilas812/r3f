# R3F プロンプト工房（Claude Code プロジェクト）

日本語で書いた「作りたい抽象3Dビジュアル」を、**React Three Fiber (R3F) の本格的なローカルプロジェクト**として実装してもらうための Claude Code プロジェクトです。アイデアを渡すと、Claude Code が (1) 良い仕様書（指示）を作り、(2) そのまま動くコードまで書いてくれます。

得意分野：**パーティクル / シェーダー / 幾何学 / 手続き型アニメーション**（抽象・アート系）。

## セットアップ
1. このフォルダ（`r3f-prompt-studio`）を好きな場所に置く。
2. ターミナルでそのフォルダに移動して `claude` を起動（Claude Code）。
3. 以上。`CLAUDE.md` は Claude Code が自動で読み込みます。

## 使い方（毎回の流れ）
1. `templates/brief-template.md` を `briefs/作品名.md` にコピーして、作りたいものを日本語で書く（空欄OK）。
2. Claude Code にこう頼む：
   > `briefs/作品名.md を読んで、まず仕様書を作って。OKしたら実際にプロジェクトを構築して`
3. 仕様書を確認し、気になる所を日本語で直してもらう。
4. 「これで実装して」と頼むと、Vite + R3F のプロジェクト一式を作ってくれる。
5. `npm install` → `npm run dev` でブラウザに表示。`leva` のGUIで数値をいじって遊ぶ。
6. 気に入ったら画面録画して、動画素材として使う。

## フォルダの中身
- `CLAUDE.md` … プロジェクトの頭脳。Claude Code が毎回自動で読む
- `knowledge/` … Claudeが参照する技術知識
  - `setup.md` … プロジェクトの作り方・依存関係
  - `r3f-basics.md` … R3Fの基本（初心者向け）
  - `techniques.md` … パーティクル/シェーダー/インスタンシング/Bloomの定石
  - `pitfalls.md` … よくある落とし穴と対処
- `templates/` … 企画書（brief）と仕様書（spec）のひな形
- `briefs/` … 自分のアイデアを書く場所
- `examples/particle-vortex/` … 完成イメージの仕様サンプル（パーティクルの渦）

## はじめの一歩
まず `examples/particle-vortex/spec.md` を見てください。仕様書の完成イメージが掴めます。そのうえで Claude Code に
> `examples/particle-vortex/spec.md の通りにプロジェクトを実装して`

と頼むと、この仕組みが一発で体験できます。慣れたら自分の `briefs/` で同じことをするだけです。

## 用語ミニ解説（初心者向け）
- **R3F（React Three Fiber）**：3DライブラリThree.jsを、Reactの書き方で扱えるようにしたもの。
- **パーティクル**：点や小さな粒を大量に表示して、煙・星・流れなどを表現する手法。
- **シェーダー（GLSL）**：GPUで動く小さなプログラム。色や形の動きを高速・滑らかに作れる。
- **インスタンシング**：同じ形を大量に、軽く描く仕組み。
- **ポストプロセス / Bloom**：描いた後に発光（にじむ光）を足すエフェクト。アート系で映える。
- **leva**：画面に出るツマミGUI。数値をリアルタイムに変えて見た目を調整できる。
